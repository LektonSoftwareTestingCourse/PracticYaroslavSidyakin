## Вне объёма

| Исключение | Причина |
|---|---|
| Остальные сервисы СМП | свои ТЗ, в этой практике — окружение |
| Публикация карточных событий в RabbitMQ, Notification Service | интеграционный уровень, модуль 5 |
| Нагрузочные характеристики | отдельный артефакт модуля 7 |
| Безопасность (шифрование PAN, аутентификация) | не предусмотрена архитектурой учебного стенда |
| Схема БД и миграции | проверяются косвенно, через поведение API |
