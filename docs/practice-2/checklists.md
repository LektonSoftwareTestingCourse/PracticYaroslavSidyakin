# Чек-листы: Authorization и Card Management

Перед прогоном: `docker compose down -v && docker compose up -d`, дождаться
`healthy` у всех контейнеров.

Чек-лист фиксирует, **что** проверено. Конкретные входные данные, шаги и
ожидаемые результаты — в тест-кейсах [`test-design.md`](test-design.md),
на которые ссылается колонка «Кейсы».

по порядку: каждый опирается на состояние, созданное предыдущим.
